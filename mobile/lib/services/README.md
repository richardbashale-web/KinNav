# Mobile Services

## Description
Points d'intégration pour géolocalisation, itinéraires et authentification.

## Technologies / structure
Dart, Geolocator et HTTP; les services doivent consommer les contrats versionnés `api/v1`.

## Installation, lancement et tests
Voir [README mobile](../../README.md).

## Variables
`KINNAV_API_URL` et permissions natives de localisation.

## Interfaces
La géolocalisation est utilisée par l'écran carte; les appels API sont en cours d'intégration.
