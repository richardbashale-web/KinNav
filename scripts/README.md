# Scripts KinNav

## Description
Aides de développement local.

## Technologies / structure
Scripts shell portables; `setup.sh` vérifie les outils et `deploy.sh` démarre Compose.

## Installation / lancement
Exécuter depuis la racine avec un shell POSIX, ou utiliser `docker compose` directement sous Windows.

## Tests
Les scripts retournent un code non nul si une commande échoue.

## Variables
Les variables sont chargées par Docker Compose depuis `.env`.

## API
Aucune.

## Maintenance
Équipe KinNav.
