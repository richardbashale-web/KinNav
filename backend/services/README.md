# Services backend

## Description et technologies
Microservices MVP indépendants : auth et profil NestJS, routage Go, trafic FastAPI.

## Structure
Chaque sous-dossier possède son code, ses tests et son guide d'installation.

## Installation / lancement
`docker compose up --build` à la racine, ou suivre les commandes de chaque service.

## Tests
`make test`.

## Variables
Voir `.env.example` à la racine; ne pas committer de fichier `.env`.

## Contrats
Voir `docs/api/README.md` et les README de service.
